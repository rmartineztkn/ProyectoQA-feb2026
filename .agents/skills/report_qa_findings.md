# Skill: Report QA Findings

## Purpose
Systematically document bugs, test results, and performance observations.

## Instructions
1. After any test execution, capture the stdout/stderr.
2. Format the findings into `test_results.txt` with:
   - Timestamp.
   - Test Case Name.
   - Status (PASS/FAIL).
   - Error logs (if any).
3. If a critical bug is found, create a new entry in the `PLAN_PRUEBAS.md` or a dedicated `BUGS.md`.

## Quality Standard
- Reports must be clear, reproducible, and include the environment state.
